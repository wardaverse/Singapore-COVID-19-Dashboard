# Singapore-COVID-19-Dashboard

An interactive data visualization dashboard that tracks the spread of COVID-19 across Singapore's planning areas during the early stages of the pandemic (January 21 – March 31, 2020), with predictive modeling extending through December 2021.

## Features

* Geographic visualization of confirmed cases across Singapore's various cities/regions
* Time-series analysis of the pandemic's progression during the first wave
* Forecasted data projecting case trends through the end of 2021
* Interactive charts and maps for exploring regional patterns

## Data Source

Case data sourced from the WHO Western Pacific Region dashboard.

## Use Cases

Ideal for researchers, data enthusiasts, and anyone interested in understanding the early dynamics of COVID-19 transmission in Singapore and how predictive models compared to actual outcomes.
